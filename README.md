# A Practical Primer in Human Complex Genetics

_A Practical Primer in Human Complex Genetics_ is a hands-on guide to doing a genome-wide association study (GWAS): designing it, quality control, association testing, visualisation, and post-GWAS analyses such as clumping, regional plots, PheWAS and Mendelian randomisation. It was originally written for the **Genetic Epidemiology** course of the [Master Epidemiology](https://epidemiology-education.nl) of Utrecht University, but works as a stand-alone companion to learning GWAS.

**Read the book:** [swvanderlaan.github.io/A_Practical_Primer_in_Human_Complex_Genetics](https://swvanderlaan.github.io/A_Practical_Primer_in_Human_Complex_Genetics/). A PDF and EPUB edition are planned.

## Editions

- **CoCalc edition**: for the course, with all software and data ready in [CoCalc](https://cocalc.com).
- **Standalone edition**: for your own laptop or server, including installation instructions.

Both editions are built from the same chapters.
